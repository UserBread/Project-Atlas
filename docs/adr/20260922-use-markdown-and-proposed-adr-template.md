# Use markdown and the proposed ADR template

- Status: accepted
- Date: 2026-09-22

## Context and Problem Statement

We want a lightweight and consistent format for recording architectural decisions in this project. The structure should be easy to read, simple to author in plain text, and consistent across all ADRs in the repository.

## Considered Options

- Markdown with a simple ADR template
- Unstructured markdown notes
- A generated documentation tool such as Log4brains

## Decision Outcome

Chosen option: "Markdown with a simple ADR template", because it provides a clear and concise structure for ADRs while staying easy to maintain in the repository.
